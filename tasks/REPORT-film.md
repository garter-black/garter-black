## Determinism

No runtime randomness. Mote table is pre-generated by a seeded script (`gen-motes.py`) and baked into data attributes; grain is a base64 SVG turbulence tile; GSAP 3.14.2 is vendored locally at `assets/gsap.min.js` in both projects; no network at render time. All tweens live on a paused `window.__timelines[...]` timeline and both loops settle back to the exact first-frame state.
